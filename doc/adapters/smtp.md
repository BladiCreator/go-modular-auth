# SMTP Email Adapter

The **SMTP Adapter** (`adapters/smtp`) delivers transactional notification emails generated by GoModularAuth (email verification, password reset links, magic links, OTP codes).

---

## Installation

```bash
go get github.com/BladiCreator/go-modular-auth/adapters/smtp
```

---

## Configuration & Usage

```go
package main

import (
    "log"

    auth "github.com/BladiCreator/go-modular-auth"
    "github.com/BladiCreator/go-modular-auth/adapters/smtp"
)

func main() {
    // 1. Configure the SMTP sender
    mailer, err := smtp.New(smtp.Config{
        Host:               "smtp.mailgun.org",
        Port:               587,
        Username:           "postmaster@your-domain.com",
        Password:           "secret-smtp-password",
        From:               "Security Team <no-reply@your-domain.com>",
        UseTLS:             false, // Port 587 uses STARTTLS automatically
        InsecureSkipVerify: false,
    })
    if err != nil {
        log.Fatalf("failed to initialize SMTP sender: %v", err)
    }

    // 2. Wire into Auth Engine
    engine, err := auth.New(auth.Config{
        Store: myStore,
        Email: mailer,
        EmailVerification: auth.EmailVerificationConfig{
            Required:     true,
            SendOnSignUp: true,
        },
    })
    if err != nil {
        log.Fatal(err)
    }

    _ = engine
}
```

---

## Technical Capabilities

1. **STARTTLS and Direct TLS**: Supports standard submission ports (587 via STARTTLS) as well as direct TLS ports (465).
2. **Multipart/Alternative MIME**: Generates compliant MIME bodies containing both plain-text (`text/plain; charset=UTF-8`) and HTML (`text/html; charset=UTF-8`) alternatives with unique boundary markers.
3. **Context-Aware Dialing**: Uses `net.Dialer.DialContext` to respect request timeouts and cancellation deadlines.
