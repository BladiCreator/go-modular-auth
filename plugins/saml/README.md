# gomodularauth-saml

`gomodularauth-saml` provides enterprise-grade SAML 2.0 (Security Assertion Markup Language) identity federation for [GoModularAuth](https://github.com/BladiCreator/go-modular-auth). It acts as a compliant SAML 2.0 Service Provider (SP), abstracting all XML, XMLDSig, and cryptographic complexity away from Core authentication while seamlessly integrating federated identities into Core `User`, `Account` (`saml:<provider_id>`), and `Session` entities.

## Installation

```bash
go get github.com/BladiCreator/go-modular-auth/plugins/saml
```
