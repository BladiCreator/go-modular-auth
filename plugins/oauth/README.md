# GoModularAuth OAuth Plugin (`gomodularauth-oauth`)

Generic, provider-agnostic OAuth 2.0 and OpenID Connect (OIDC) client plugin for [GoModularAuth](https://github.com/BladiCreator/go-modular-auth). Provides enterprise-grade authentication via external identity providers (Google, GitHub, GitLab, Discord, Microsoft, Keycloak, Auth0, etc.) with strict adherence to RFC 6749, RFC 7636 (PKCE), cryptographically validated state anti-replay protection, safe account linking policies, and native integration with GoModularAuth Core.

## Installation

```bash
go get github.com/BladiCreator/go-modular-auth/plugins/oauth
```
