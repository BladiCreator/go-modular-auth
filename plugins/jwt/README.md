# GoModularAuth JWT Plugin (`gomodularauth-jwt`)

An optional, production-grade JWT (JSON Web Token) plugin library for **[GoModularAuth](https://github.com/BladiCreator/go-modular-auth)**. It provides stateless, cryptographically signed token issuance and verification for integrations requiring decoupled or distributed token verification (e.g. public APIs, microservices, OAuth2/OIDC interoperability, and mobile clients) **without replacing Core server-side opaque Sessions**.

## Installation

```bash
go get github.com/BladiCreator/go-modular-auth/plugins/jwt
```
